       26.1 Theorem (Ramsey's theorem)
       26.2 Theorem (Infinitary Ramsey's theorem)
       26.3 Lemma   (König's lemma)

   An application of the compactness theorem of propositional logic: the
   proof goes through König's lemma, which is obtained from the compactness
   theorem in the AFP entry Prop_Compactness.

theory RamseyFinite
imports 
  "HOL-Library.Ramsey"
  "Prop_Compactness.KoenigLemma"

begin

section ‹Ramsey's Theorem (finitary version)›

text ‹This theory formalizes Ramsey's theorem \<^cite>‹Ramsey1930› in its finitary
  version, following the presentation of Boolos, Burgess and Jeffrey
  \<^cite>‹BoolosBJ2007›.  The finitary Ramsey theorem (Theorem 26.1) is obtained, as
  in the book, by a detour through the infinite: it follows from the infinitary
  version (Theorem 26.2, theorem @{thm [source] Ramsey.Ramsey} of
  \<^theory>‹HOL-Library.Ramsey›) together with König's lemma \<^cite>‹Koenig1927›
  (Lemma 26.3, theorem @{thm [source] Koenig_Lemma} of the theory
  \<^theory>‹Prop_Compactness.KoenigLemma›, proved there from the compactness
  theorem of propositional logic).

  The development proceeds in five steps:
  ▸ Theorem 26.2, the infinitary Ramsey theorem, restated in the notation of
    the book;
  ▸ König's lemma, transferred from trees whose nodes belong to a countable
    type to trees whose set of nodes is countable;
  ▸ the tree of partitions of ‹[{0,…,m-1}]⇗r⇖› having no size-‹n›
    homogeneous set, ordered by extension;
  ▸ the proof that this tree is infinite when Theorem 26.1 fails;
  ▸ Theorem 26.1 itself: König's lemma yields an infinite branch, whose
    partitions glue together into a partition of ‹[ω]⇗r⇖›; an infinite
    homogeneous set of the latter, given by Theorem 26.2, contains a size-‹n›
    homogeneous set of a node of the tree, a contradiction.

  References to the book are to its 5th edition \<^cite>‹BoolosBJ2007›.  The
  infinitary theorem was first formalized in Isabelle/HOL by Ridge
  \<^cite>‹"Ramsey-Infinite-AFP"›, following the 3rd edition of the book; that
  development has since been incorporated into \<^theory>‹HOL-Library.Ramsey›,
  whose theorem @{thm [source] Ramsey.Ramsey} is used here.›


subsection ‹An application of the compactness theorem›

text ‹This theory is one more application of the compactness theorem of
  propositional logic, formalized in the AFP entry ‹Prop_Compactness›
  \<^cite>‹SerranoAFP2024›, which follows the model existence approach of Smullyan
  and Fitting \<^cite>‹Smullyan and Fitting› and builds on an earlier Isar
  formalization of first-order meta-logic \<^cite>‹Serrano2011›.  That entry
  obtains from compactness Hall's theorem for countable families of sets
  \<^cite>‹Serrano2022› and for countable bipartite graphs \<^cite>‹Serrano2024›, the
  de Bruijn--Erdős ‹k›-colouring theorem for infinite graphs
  \<^cite>‹DeBruijnErdos1951› and König's lemma; the countable version of Dilworth's
  theorem, in the AFP entry ‹Dilworth_Countable› \<^cite>‹"Dilworth_Countable-AFP"›
  (see also \<^cite>‹SerranoLANMR2026›), also builds on it.

  The finite Ramsey theorem depends on compactness through König's lemma, along
  the following chain:
  ▪ @{thm [source] Compactness_Theorem} (theory
    \<^theory>‹Prop_Compactness.PropCompactness›): a set of propositional formulas
    is satisfiable if every finite subset of it is satisfiable;
  ▪ @{thm [source] Koenig_Lemma} (theory \<^theory>‹Prop_Compactness.KoenigLemma›),
    proved directly from compactness: an infinite, finitely branching tree is
    described by a set of formulas whose propositional letters are its nodes,
    stating that each level contains a chosen node, that the predecessors of
    a chosen node are chosen, and that no two nodes of a level are chosen.
    Every finite subset of this set is satisfiable, since the tree has nodes
    at all levels; by compactness the whole set is satisfiable, and the nodes
    true under a satisfying valuation form an infinite path;
  ▪ ‹Koenig_Lemma_countable› (below) transfers König's lemma to trees
    whose ∗‹set› of nodes is countable;
  ▪ ‹Ramsey_Theorem› (below) applies it to the tree of partitions without
    size-‹n› homogeneous sets.

  In contrast, and perhaps surprisingly, the infinitary Ramsey theorem does not
  depend on compactness at all.  The theorem @{thm [source] Ramsey.Ramsey} of
  \<^theory>‹HOL-Library.Ramsey› is proved there by induction on the size ‹r› of
  the subsets, with no use of logic.  Thus the infinite statement has a direct
  combinatorial proof, while its finite consequence, obtained from it as in the
  book, needs compactness: compactness is used precisely to pass from the
  infinite to the finite.

  This dependency is a feature of the proof, not of the theorem:
  \<^theory>‹HOL-Library.Ramsey› also contains purely finitary proofs of the finite
  Ramsey theorem, which give explicit upper bounds for ‹m›, starting with the
  bound of Erdős and Szekeres \<^cite>‹ErdosSzekeres1935›.  The proof
  formalized here is non-constructive: it shows that ‹m› exists without
  bounding it.›


subsection ‹Notation›

text ‹As in the book, ‹ω› is the set of natural numbers and ‹[X]⇗r⇖› is the
  collection of all size-‹r› subsets of ‹X› (notation ‹nsets› of
  ‹HOL-Library.Ramsey›).  A partition of ‹[X]⇗r⇖› into ‹s› classes is a function
  ‹f : [X]⇗r⇖ → {1,…,s}›, written ‹f ∈ [X]⇗r⇖ → {1..s}›; a set ‹Y› is
  homogeneous for ‹f› when ‹f : [Y]⇗r⇖ → {j}› for some ‹j›.›

abbreviation omega :: "nat set" (‹ω›)
  where "ω ≡ UNIV"

text ‹‹homogeneous r f Y› states that ‹Y› is homogeneous for the partition ‹f›
  of the size-‹r› sets: ‹f› takes a single value on ‹[Y]⇗r⇖›.  It is an
  abbreviation, hence it is unfolded when the theory is parsed and the proofs
  below work directly on its expansion.›

abbreviation homogeneous :: "nat ⇒ ('a set ⇒ 'b) ⇒ 'a set ⇒ bool" where
  "homogeneous r f Y ≡ ∃j. f ∈ [Y]⇗r⇖ → {j}"


subsection ‹Theorem 26.2 (Infinitary Ramsey's theorem)›

text ‹Statement of Theorem 26.2 in the notation of the book: if
  ‹f : [ω]⇗r⇖ → {1,…,s}›, then there is an infinite ‹Y ⊆ ω› and a ‹j› with
  ‹1 ≤ j ≤ s› such that ‹f : [Y]⇗r⇖ → {j}›.  It is a direct reformulation of
  the theorem @{thm [source] Ramsey.Ramsey} (with ‹s+1› colours ‹0,…,s›).  This step does not
  use the compactness theorem.›

theorem Infinitary_Ramsey_Theorem:
  fixes r s :: nat
  assumes "0 < r" and "0 < s"
    and f: "f ∈ [ω]⇗r⇖ → {1..s}"
  shows "∃Y ⊆ ω. infinite Y ∧ (∃j ∈ {1..s}. f ∈ [Y]⇗r⇖ → {j})"
proof -
  have "∀X. X ⊆ ω ∧ finite X ∧ card X = r ⟶ f X < Suc s"
  proof (intro allI impI)
    fix X
    assume "X ⊆ ω ∧ finite X ∧ card X = r"
    hence "X ∈ [ω]⇗r⇖" by (simp add: nsets_def)
    hence "f X ∈ {1..s}" using f by (rule funcset_mem[rotated])
    thus "f X < Suc s" by simp
  qed
  moreover have "infinite ω" by simp
  ultimately obtain Y j where Y: "Y ⊆ ω" "infinite Y"
    and hom: "∀X. X ⊆ Y ∧ finite X ∧ card X = r ⟶ f X = j"
    using Ramsey.Ramsey[where Z = ω and s = "Suc s" and r = r and f = f]
    by blast
  have fY: "f ∈ [Y]⇗r⇖ → {j}"
    using hom by (auto simp: nsets_def)
  obtain X where X: "X ⊆ Y" "finite X" "card X = r"
    using infinite_arbitrarily_large[OF Y(2)] by blast
  hence "X ∈ [ω]⇗r⇖" by (simp add: nsets_def)
  hence "f X ∈ {1..s}" using f by (rule funcset_mem[rotated])
  moreover have "f X = j" using hom X by blast
  ultimately have "j ∈ {1..s}" by simp
  thus ?thesis using Y fY by blast
qed


subsection ‹König's lemma for trees with a countable set of nodes›

text ‹This is where the compactness theorem enters the proof: the theorem
  ‹Koenig_Lemma› used below is proved from it in the theory ‹KoenigLemma›.

  In the theory ‹KoenigLemma› the nodes of the tree must belong to a
  countable ∗‹type›.  The nodes of the tree used in the proof of Theorem 26.1
  are partitions, i.e. functions on sets of natural numbers, whose type is not
  countable, although the ∗‹set› of nodes is countable.  Hence we first transfer
  König's lemma to trees whose set of nodes is countable, by means of an
  injective map into the natural numbers.

  The idea is a relabelling of the nodes: if ‹h› is injective on the set ‹A›
  of nodes, the image of the tree ‹(A, r)› under ‹h› is the tree
  ‹(h ` A, rel_image h r)›, and each notion involved in König's lemma
  (predecessors, height, strict partial order, minimum, tree, immediate
  successors, finite branching, path) is preserved by this relabelling.  Taking
  for ‹h› an injection of ‹A› into ‹nat›, König's lemma applies to the image
  tree, and the infinite path it provides is carried back to ‹(A, r)› through
  the inverse of ‹h›.

  The relation ‹rel_image h r› is the image of ‹r› under ‹h› applied to both
  components, i.e. ‹map_prod h h ` r› in the notation of the library.›

definition rel_image :: "('a ⇒ 'b) ⇒ ('a × 'a) set ⇒ ('b × 'b) set" where
  "rel_image h r = (λ(x, y). (h x, h y)) ` r"

lemma rel_image_iff:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and x: "x ∈ A" and y: "y ∈ A"
  shows "(h x, h y) ∈ rel_image h r ⟷ (x, y) ∈ r"
proof
  assume "(h x, h y) ∈ rel_image h r"
  then obtain u v where uv: "(u, v) ∈ r" and hu: "h u = h x" and hv: "h v = h y"
    unfolding rel_image_def by auto
  have "u ∈ A" and "v ∈ A" using uv r by auto
  hence "u = x" and "v = y" using hu hv h x y by (auto dest: inj_onD)
  thus "(x, y) ∈ r" using uv by simp
next
  assume "(x, y) ∈ r"
  thus "(h x, h y) ∈ rel_image h r" unfolding rel_image_def by force
qed

lemma rel_image_subset:
  assumes "r ⊆ A × A"
  shows "rel_image h r ⊆ h ` A × h ` A"
  using assms unfolding rel_image_def by auto

lemma predecessors_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and a: "a ∈ A"
  shows "predecessors (h ` A) (h a) (rel_image h r) = h ` predecessors A a r"
proof
  show "predecessors (h ` A) (h a) (rel_image h r) ⊆ h ` predecessors A a r"
  proof
    fix u
    assume "u ∈ predecessors (h ` A) (h a) (rel_image h r)"
    hence u: "u ∈ h ` A" "(u, h a) ∈ rel_image h r"
      by (simp_all add: predecessors_def)
    then obtain x where x: "x ∈ A" "u = h x" by auto
    have "(x, a) ∈ r" using u(2) x rel_image_iff[OF h r x(1) a] by simp
    thus "u ∈ h ` predecessors A a r" using x by (auto simp: predecessors_def)
  qed
next
  show "h ` predecessors A a r ⊆ predecessors (h ` A) (h a) (rel_image h r)"
  proof
    fix u
    assume "u ∈ h ` predecessors A a r"
    then obtain x where x: "x ∈ A" "(x, a) ∈ r" "u = h x"
      by (auto simp: predecessors_def)
    have "(h x, h a) ∈ rel_image h r" using x(2) rel_image_iff[OF h r x(1) a] by simp
    thus "u ∈ predecessors (h ` A) (h a) (rel_image h r)"
      using x by (auto simp: predecessors_def)
  qed
qed

lemma height_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and a: "a ∈ A"
  shows "height (h ` A) (h a) (rel_image h r) = height A a r"
proof -
  have "predecessors A a r ⊆ A" by (auto simp: predecessors_def)
  hence "inj_on h (predecessors A a r)" using h inj_on_subset by blast
  thus ?thesis using predecessors_image[OF h r a] by (simp add: height_def card_image)
qed

lemma total_on_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and P: "P ⊆ A"
    and t: "total_on P r"
  shows "total_on (h ` P) (rel_image h r)"
proof (unfold total_on_def, intro ballI impI)
  fix u v
  assume "u ∈ h ` P" and "v ∈ h ` P" and uv: "u ≠ v"
  then obtain x y where x: "x ∈ P" "u = h x" and y: "y ∈ P" "v = h y" by auto
  have "x ≠ y" using uv x y by auto
  hence "(x, y) ∈ r ∨ (y, x) ∈ r" using t x(1) y(1) unfolding total_on_def by blast
  thus "(u, v) ∈ rel_image h r ∨ (v, u) ∈ rel_image h r"
    using x y unfolding rel_image_def by force
qed

lemma spo_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and spo: "strict_part_order A r"
  shows "strict_part_order (h ` A) (rel_image h r)"
proof -
  have irr: "irrefl_on A r" and tr: "trans_on A r"
    using spo by (auto simp: strict_part_order_def)
  have "irrefl_on (h ` A) (rel_image h r)"
  proof (unfold irrefl_on_def, intro ballI)
    fix u
    assume "u ∈ h ` A"
    then obtain x where x: "x ∈ A" "u = h x" by auto
    have "(x, x) ∉ r" using irr x(1) unfolding irrefl_on_def by blast
    thus "(u, u) ∉ rel_image h r" using rel_image_iff[OF h r x(1) x(1)] x(2) by simp
  qed
  moreover have "trans_on (h ` A) (rel_image h r)"
  proof (unfold trans_on_def, intro ballI impI)
    fix u v w
    assume "u ∈ h ` A" "v ∈ h ` A" "w ∈ h ` A"
      and uv: "(u, v) ∈ rel_image h r" and vw: "(v, w) ∈ rel_image h r"
    then obtain x y z where x: "x ∈ A" "u = h x" and y: "y ∈ A" "v = h y"
      and z: "z ∈ A" "w = h z" by auto
    have "(x, y) ∈ r" using uv rel_image_iff[OF h r x(1) y(1)] x(2) y(2) by simp
    moreover have "(y, z) ∈ r" using vw rel_image_iff[OF h r y(1) z(1)] y(2) z(2) by simp
    ultimately have "(x, z) ∈ r" using tr x(1) y(1) z(1) unfolding trans_on_def by blast
    thus "(u, w) ∈ rel_image h r" using rel_image_iff[OF h r x(1) z(1)] x(2) z(2) by simp
  qed
  ultimately show ?thesis by (simp add: strict_part_order_def)
qed

lemma minimum_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and m: "minimum A a r"
  shows "minimum (h ` A) (h a) (rel_image h r)"
proof -
  have a: "a ∈ A" and min: "∀x∈A. x ≠ a ⟶ (a, x) ∈ r"
    using m by (auto simp: minimum_def)
  have "∀u ∈ h ` A. u ≠ h a ⟶ (h a, u) ∈ rel_image h r"
  proof (intro ballI impI)
    fix u
    assume "u ∈ h ` A" and ua: "u ≠ h a"
    then obtain x where x: "x ∈ A" "u = h x" by auto
    hence "x ≠ a" using ua by auto
    hence "(a, x) ∈ r" using min x(1) by simp
    thus "(h a, u) ∈ rel_image h r" using rel_image_iff[OF h r a x(1)] x(2) by simp
  qed
  thus ?thesis using a by (simp add: minimum_def)
qed

lemma tree_image:
  assumes h: "inj_on h A" and t: "tree A r"
  shows "tree (h ` A) (rel_image h r)"
proof -
  have r: "r ⊆ A × A" and rne: "r ≠ {}" and spo: "strict_part_order A r"
    and min: "∃a. minimum A a r"
    and preds: "∀a∈A. finite (predecessors A a r) ∧ total_on (predecessors A a r) r"
    using t unfolding tree_def by auto
  have "rel_image h r ⊆ h ` A × h ` A" using r by (rule rel_image_subset)
  moreover have "rel_image h r ≠ {}" using rne by (simp add: rel_image_def)
  moreover have "strict_part_order (h ` A) (rel_image h r)" using spo_image[OF h r spo] .
  moreover have "∃b. minimum (h ` A) b (rel_image h r)"
    using min minimum_image[OF h r] by blast
  moreover have "∀b ∈ h ` A. finite (predecessors (h ` A) b (rel_image h r)) ∧
                   total_on (predecessors (h ` A) b (rel_image h r)) (rel_image h r)"
  proof
    fix b
    assume "b ∈ h ` A"
    then obtain a where a: "a ∈ A" "b = h a" by auto
    have eq: "predecessors (h ` A) b (rel_image h r) = h ` predecessors A a r"
      using predecessors_image[OF h r a(1)] a(2) by simp
    have "finite (predecessors A a r)" and tot: "total_on (predecessors A a r) r"
      using preds a(1) by auto
    moreover have "predecessors A a r ⊆ A" by (auto simp: predecessors_def)
    ultimately show "finite (predecessors (h ` A) b (rel_image h r)) ∧
                     total_on (predecessors (h ` A) b (rel_image h r)) (rel_image h r)"
      using eq total_on_image[OF h r] by simp
  qed
  ultimately show ?thesis by (simp add: tree_def)
qed

lemma imm_successors_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and a: "a ∈ A"
  shows "imm_successors (h ` A) (h a) (rel_image h r) = h ` imm_successors A a r"
proof
  show "imm_successors (h ` A) (h a) (rel_image h r) ⊆ h ` imm_successors A a r"
  proof
    fix u
    assume "u ∈ imm_successors (h ` A) (h a) (rel_image h r)"
    hence u: "u ∈ h ` A" "(h a, u) ∈ rel_image h r"
      "height (h ` A) u (rel_image h r) = height (h ` A) (h a) (rel_image h r) + 1"
      by (simp_all add: imm_successors_def)
    then obtain x where x: "x ∈ A" "u = h x" by auto
    have "(a, x) ∈ r" using u(2) x rel_image_iff[OF h r a x(1)] by simp
    moreover have "height A x r = height A a r + 1"
      using u(3) x height_image[OF h r x(1)] height_image[OF h r a] by simp
    ultimately show "u ∈ h ` imm_successors A a r"
      using x by (auto simp: imm_successors_def)
  qed
next
  show "h ` imm_successors A a r ⊆ imm_successors (h ` A) (h a) (rel_image h r)"
  proof
    fix u
    assume "u ∈ h ` imm_successors A a r"
    then obtain x where x: "x ∈ A" "(a, x) ∈ r" "height A x r = height A a r + 1"
      "u = h x" by (auto simp: imm_successors_def)
    have "(h a, u) ∈ rel_image h r" using rel_image_iff[OF h r a x(1)] x by simp
    moreover have "height (h ` A) u (rel_image h r) = height (h ` A) (h a) (rel_image h r) + 1"
      using x height_image[OF h r x(1)] height_image[OF h r a] by simp
    ultimately show "u ∈ imm_successors (h ` A) (h a) (rel_image h r)"
      using x by (auto simp: imm_successors_def)
  qed
qed

lemma finitely_branching_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and fb: "finitely_branching A r"
  shows "finitely_branching (h ` A) (rel_image h r)"
proof (unfold finitely_branching_def, intro ballI)
  fix b
  assume "b ∈ h ` A"
  then obtain a where a: "a ∈ A" "b = h a" by auto
  have "finite (imm_successors A a r)" using fb a(1) by (simp add: finitely_branching_def)
  thus "finite (imm_successors (h ` A) b (rel_image h r))"
    using imm_successors_image[OF h r a(1)] a(2) by simp
qed

lemma path_image:
  assumes h: "inj_on h A" and r: "r ⊆ A × A" and p: "path B A r"
  shows "path (h ` B) (h ` A) (rel_image h r)"
proof -
  have BA: "B ⊆ A" and spo: "strict_part_order A r" and tot: "total_on B r"
    and max: "∀C. B ⊆ C ∧ sub_linear_order C A r ⟶ B = C"
    using p by (auto simp: path_def sub_linear_order_def)
  have slo: "sub_linear_order (h ` B) (h ` A) (rel_image h r)"
    using BA spo_image[OF h r spo] total_on_image[OF h r BA tot]
    by (auto simp: sub_linear_order_def)
  have "h ` B = C'"
    if C': "h ` B ⊆ C'" "sub_linear_order C' (h ` A) (rel_image h r)" for C'
  proof -
    let ?g = "inv_into A h"
    let ?C = "?g ` C'"
    have C'A: "C' ⊆ h ` A" and totC': "total_on C' (rel_image h r)"
      using C'(2) by (auto simp: sub_linear_order_def)
    have hC: "h ` ?C = C'" using image_inv_into_cancel[OF refl C'A] .
    have CA: "?C ⊆ A" using C'A by (auto intro: inv_into_into)
    have "total_on ?C r"
    proof (unfold total_on_def, intro ballI impI)
      fix x y
      assume x: "x ∈ ?C" and y: "y ∈ ?C" and xy: "x ≠ y"
      have xA: "x ∈ A" and yA: "y ∈ A" using x y CA by auto
      have "h x ∈ C'" and "h y ∈ C'" using x y hC by auto
      moreover have "h x ≠ h y" using xy xA yA h by (auto dest: inj_onD)
      ultimately have "(h x, h y) ∈ rel_image h r ∨ (h y, h x) ∈ rel_image h r"
        using totC' unfolding total_on_def by blast
      thus "(x, y) ∈ r ∨ (y, x) ∈ r"
        using rel_image_iff[OF h r xA yA] rel_image_iff[OF h r yA xA] by simp
    qed
    hence "sub_linear_order ?C A r" using CA spo by (simp add: sub_linear_order_def)
    moreover have "B ⊆ ?C"
    proof
      fix b
      assume b: "b ∈ B"
      hence "h b ∈ C'" using C'(1) by auto
      moreover have "?g (h b) = b" using b BA h by auto
      ultimately show "b ∈ ?C" by force
    qed
    ultimately have "B = ?C" using max by blast
    thus "h ` B = C'" using hC by simp
  qed
  thus ?thesis using slo unfolding path_def by blast
qed

text ‹Relabelling by ‹h› and then by its inverse gives back the original relation.›

lemma rel_image_inv_into:
  assumes h: "inj_on h A" and r: "r ⊆ A × A"
  shows "rel_image (inv_into A h) (rel_image h r) = r"
proof
  show "rel_image (inv_into A h) (rel_image h r) ⊆ r"
  proof
    fix p
    assume "p ∈ rel_image (inv_into A h) (rel_image h r)"
    then obtain x y where xy: "(x, y) ∈ r" and p: "p = (inv_into A h (h x), inv_into A h (h y))"
      unfolding rel_image_def by auto
    have "x ∈ A" and "y ∈ A" using xy r by auto
    thus "p ∈ r" using p xy h by simp
  qed
next
  show "r ⊆ rel_image (inv_into A h) (rel_image h r)"
  proof
    fix p
    assume p: "p ∈ r"
    then obtain x y where xy: "p = (x, y)" by (cases p) auto
    have "x ∈ A" and "y ∈ A" using p xy r by auto
    hence "p = (inv_into A h (h x), inv_into A h (h y))" using xy h by simp
    thus "p ∈ rel_image (inv_into A h) (rel_image h r)"
      using p xy unfolding rel_image_def by force
  qed
qed

theorem Koenig_Lemma_countable:
  assumes t: "tree A r" and c: "countable A" and inf: "infinite A"
    and fb: "finitely_branching A r"
  shows "∃B. infinite_path B A r"
proof -
  let ?h = "to_nat_on A"
  have h: "inj_on ?h A" using c by (rule inj_on_to_nat_on)
  have r: "r ⊆ A × A" using t by (simp add: tree_def)
  have "infinite_tree (?h ` A) (rel_image ?h r)"
    using tree_image[OF h t] inf finite_image_iff[OF h] by simp
  moreover have "finitely_branching (?h ` A) (rel_image ?h r)"
    using finitely_branching_image[OF h r fb] .
  ultimately obtain B' where B': "infinite_path B' (?h ` A) (rel_image ?h r)"
    using Koenig_Lemma by blast
  hence pB': "path B' (?h ` A) (rel_image ?h r)" and iB': "infinite B'"
    by (simp_all add: infinite_path_def)
  have B'A: "B' ⊆ ?h ` A" using pB' by (simp add: path_def sub_linear_order_def)
  let ?g = "inv_into A ?h"
  have g: "inj_on ?g (?h ` A)" by (rule inj_on_inv_into) simp
  have r': "rel_image ?h r ⊆ ?h ` A × ?h ` A" using r by (rule rel_image_subset)
  have gA: "?g ` ?h ` A = A" using h by simp
  have gr: "rel_image ?g (rel_image ?h r) = r" using rel_image_inv_into[OF h r] .
  have "path (?g ` B') A r" using path_image[OF g r' pB'] gA gr by simp
  moreover have "infinite (?g ` B')"
    using iB' finite_image_iff[OF inj_on_subset[OF g B'A]] by simp
  ultimately show ?thesis by (auto simp: infinite_path_def)
qed


subsection ‹The tree of partitions without size-‹n› homogeneous sets›

text ‹The nodes of the tree are the pairs ‹(m, f)› where
  ‹f : [{0,…,m-1}]⇗r⇖ → {1,…,s}› is a partition having no size-‹n›
  homogeneous set.  The partition ‹f› is taken extensional (it takes the
  value ‹undefined› outside its domain), so that it is determined by its values
  on ‹[{0,…,m-1}]⇗r⇖›.  The node ‹(m, f)› lies at level ‹m›.

  In the book the levels are ‹T⇩k›, formed by the partitions with ‹m = n + k›.
  The formalization of König's lemma requires a tree with a single root, so here
  all values ‹m ≥ 0› are used: the root is the empty partition (‹m = 0›), and
  for ‹m < n› no partition has a size-‹n› homogeneous set.

  The book relates ‹f› and ‹g› when ‹g› is at the next level and extends ‹f›;
  the formalized König's lemma uses the corresponding strict order, so ‹f› is
  related with ‹g› when ‹g› is at a higher level and extends ‹f›, i.e. ‹g›
  assigns the same value as does ‹f› to any argument in the domain of ‹f›.

  Accordingly, ‹Tnodes r s n› is the set of nodes of the tree (the partitions
  without size-‹n› homogeneous sets, paired with their levels), and
  ‹Rext r s n› is the extension order between them.›

definition Tnodes :: "nat ⇒ nat ⇒ nat ⇒ (nat × (nat set ⇒ nat)) set" where
  "Tnodes r s n = {(m, f). f ∈ [{0..<m}]⇗r⇖ →⇩E {1..s} ∧
                           ¬ (∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r f Y)}"

definition Rext ::
  "nat ⇒ nat ⇒ nat ⇒ ((nat × (nat set ⇒ nat)) × (nat × (nat set ⇒ nat))) set" where
  "Rext r s n = {((m, f), (m', g)). (m, f) ∈ Tnodes r s n ∧ (m', g) ∈ Tnodes r s n ∧
                    m < m' ∧ (∀x ∈ [{0..<m}]⇗r⇖. g x = f x)}"

lemma Tnodes_iff:
  "(m, f) ∈ Tnodes r s n ⟷
     f ∈ [{0..<m}]⇗r⇖ →⇩E {1..s} ∧ ¬ (∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r f Y)"
  by (simp add: Tnodes_def)

lemma Rext_iff:
  "((m, f), (m', g)) ∈ Rext r s n ⟷
     (m, f) ∈ Tnodes r s n ∧ (m', g) ∈ Tnodes r s n ∧ m < m' ∧
     (∀x ∈ [{0..<m}]⇗r⇖. g x = f x)"
  by (simp add: Rext_def)

lemma nsets_interval_mono:
  fixes m m' :: nat
  assumes "m ≤ m'"
  shows "[{0..<m}]⇗r⇖ ⊆ [{0..<m'}]⇗r⇖"
  using assms by (intro nsets_mono) auto

lemma nsets_interval_zero:
  assumes "0 < r"
  shows "[{0..<0::nat}]⇗r⇖ = {}"
  using assms by (auto simp: nsets_def)

text ‹Restricting a partition without size-‹n› homogeneous sets to a smaller
  initial segment gives a node of the tree.›

lemma node_restrict:
  assumes f: "f ∈ [{0..<M}]⇗r⇖ → {1..s}"
    and noh: "¬ (∃Y ∈ [{0..<M}]⇗n⇖. homogeneous r f Y)"
    and mM: "m ≤ M"
  shows "(m, restrict f ([{0..<m}]⇗r⇖)) ∈ Tnodes r s n"
proof -
  let ?D = "[{0..<m}]⇗r⇖"
  have sub: "?D ⊆ [{0..<M}]⇗r⇖" using mM by (rule nsets_interval_mono)
  have "∀x ∈ ?D. f x ∈ {1..s}" using f sub by (auto intro: funcset_mem)
  hence 1: "restrict f ?D ∈ ?D →⇩E {1..s}" by (simp add: restrict_PiE_iff)
  have 2: "¬ (∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r (restrict f ?D) Y)"
  proof
    assume "∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r (restrict f ?D) Y"
    then obtain Y j where Y: "Y ∈ [{0..<m}]⇗n⇖"
      and hj: "restrict f ?D ∈ [Y]⇗r⇖ → {j}" by blast
    have Ym: "Y ⊆ {0..<m}" using Y by (simp add: nsets_def)
    have "Y ∈ [{0..<M}]⇗n⇖" using Y nsets_interval_mono[OF mM] by blast
    moreover have "f ∈ [Y]⇗r⇖ → {j}"
    proof (rule Pi_I)
      fix x
      assume x: "x ∈ [Y]⇗r⇖"
      hence xD: "x ∈ ?D" using Ym nsets_mono by blast
      have "restrict f ?D x ∈ {j}" using hj x by (rule funcset_mem)
      thus "f x ∈ {j}" using xD by simp
    qed
    ultimately show False using noh by blast
  qed
  from 1 2 show ?thesis by (simp add: Tnodes_def)
qed

lemma node_restrict_node:
  assumes g: "(M, g) ∈ Tnodes r s n" and mM: "m ≤ M"
  shows "(m, restrict g ([{0..<m}]⇗r⇖)) ∈ Tnodes r s n"
proof (rule node_restrict[OF _ _ mM])
  show "g ∈ [{0..<M}]⇗r⇖ → {1..s}" using g by (simp add: Tnodes_def PiE_def)
  show "¬ (∃Y ∈ [{0..<M}]⇗n⇖. homogeneous r g Y)" using g by (simp add: Tnodes_def)
qed

lemma node_restrict_eq:
  assumes "(m, g) ∈ Tnodes r s n"
  shows "restrict g ([{0..<m}]⇗r⇖) = g"
  using assms by (auto simp: Tnodes_def)

text ‹Two restrictions of the same node are related in the tree.›

lemma Rext_restrict:
  assumes g: "(M, g) ∈ Tnodes r s n" and m12: "m1 < m2" and m2M: "m2 ≤ M"
  shows "((m1, restrict g ([{0..<m1}]⇗r⇖)), (m2, restrict g ([{0..<m2}]⇗r⇖))) ∈ Rext r s n"
proof -
  have 1: "(m1, restrict g ([{0..<m1}]⇗r⇖)) ∈ Tnodes r s n"
    using node_restrict_node[OF g] m12 m2M by simp
  have 2: "(m2, restrict g ([{0..<m2}]⇗r⇖)) ∈ Tnodes r s n"
    using node_restrict_node[OF g m2M] .
  have "[{0..<m1}]⇗r⇖ ⊆ [{0..<m2}]⇗r⇖" using m12 by (intro nsets_interval_mono) simp
  hence "∀x ∈ [{0..<m1}]⇗r⇖.
           restrict g ([{0..<m2}]⇗r⇖) x = restrict g ([{0..<m1}]⇗r⇖) x" by auto
  thus ?thesis using 1 2 m12 by (simp add: Rext_iff)
qed

lemma Rext_restrict_node:
  assumes g: "(M, g) ∈ Tnodes r s n" and mM: "m < M"
  shows "((m, restrict g ([{0..<m}]⇗r⇖)), (M, g)) ∈ Rext r s n"
  using Rext_restrict[OF g mM order_refl] node_restrict_eq[OF g] by simp

text ‹The nodes below a node ‹(M, g)› are exactly the restrictions of ‹g› to
  the levels ‹m < M›; in particular the node ‹(M, g)› has height ‹M›.›

lemma predecessors_node:
  assumes g: "(M, g) ∈ Tnodes r s n"
  shows "predecessors (Tnodes r s n) (M, g) (Rext r s n) =
           (λm. (m, restrict g ([{0..<m}]⇗r⇖))) ` {..<M}"
proof
  show "predecessors (Tnodes r s n) (M, g) (Rext r s n) ⊆
          (λm. (m, restrict g ([{0..<m}]⇗r⇖))) ` {..<M}"
  proof
    fix p
    assume "p ∈ predecessors (Tnodes r s n) (M, g) (Rext r s n)"
    hence p: "(p, (M, g)) ∈ Rext r s n" by (simp add: predecessors_def)
    obtain m f where pmf: "p = (m, f)" by (cases p) auto
    have mf: "(m, f) ∈ Tnodes r s n" and mM: "m < M"
      and agree: "∀x ∈ [{0..<m}]⇗r⇖. g x = f x"
      using p pmf by (simp_all add: Rext_iff)
    have "f ∈ [{0..<m}]⇗r⇖ →⇩E {1..s}" using mf by (simp add: Tnodes_def)
    moreover have "restrict g ([{0..<m}]⇗r⇖) ∈ [{0..<m}]⇗r⇖ →⇩E {1..s}"
      using node_restrict_node[OF g, of m] mM by (simp add: Tnodes_def)
    ultimately have "f = restrict g ([{0..<m}]⇗r⇖)"
      using agree by (intro PiE_ext) auto
    thus "p ∈ (λm. (m, restrict g ([{0..<m}]⇗r⇖))) ` {..<M}" using pmf mM by auto
  qed
next
  show "(λm. (m, restrict g ([{0..<m}]⇗r⇖))) ` {..<M} ⊆
          predecessors (Tnodes r s n) (M, g) (Rext r s n)"
  proof
    fix p
    assume "p ∈ (λm. (m, restrict g ([{0..<m}]⇗r⇖))) ` {..<M}"
    then obtain m where mM: "m < M" and pm: "p = (m, restrict g ([{0..<m}]⇗r⇖))" by auto
    have "p ∈ Tnodes r s n" using node_restrict_node[OF g, of m] mM pm by simp
    moreover have "(p, (M, g)) ∈ Rext r s n" using Rext_restrict_node[OF g mM] pm by simp
    ultimately show "p ∈ predecessors (Tnodes r s n) (M, g) (Rext r s n)"
      by (simp add: predecessors_def)
  qed
qed

lemma height_node:
  assumes g: "(M, g) ∈ Tnodes r s n"
  shows "height (Tnodes r s n) (M, g) (Rext r s n) = M"
proof -
  have "inj_on (λm. (m, restrict g ([{0..<m}]⇗r⇖))) {..<M}" by (rule inj_onI) simp
  hence "card ((λm. (m, restrict g ([{0..<m}]⇗r⇖))) ` {..<M}) = M"
    by (simp add: card_image)
  thus ?thesis using predecessors_node[OF g] by (simp add: height_def)
qed

lemma total_predecessors_node:
  assumes g: "(M, g) ∈ Tnodes r s n"
  shows "total_on (predecessors (Tnodes r s n) (M, g) (Rext r s n)) (Rext r s n)"
proof -
  let ?P = "(λm. (m, restrict g ([{0..<m}]⇗r⇖))) ` {..<M}"
  have "total_on ?P (Rext r s n)"
  proof (unfold total_on_def, intro ballI impI)
    fix p q
    assume "p ∈ ?P" and "q ∈ ?P" and pq: "p ≠ q"
    then obtain m1 m2 where m1: "m1 < M" "p = (m1, restrict g ([{0..<m1}]⇗r⇖))"
      and m2: "m2 < M" "q = (m2, restrict g ([{0..<m2}]⇗r⇖))" by auto
    have "m1 ≠ m2" using pq m1(2) m2(2) by auto
    hence "m1 < m2 ∨ m2 < m1" by arith
    thus "(p, q) ∈ Rext r s n ∨ (q, p) ∈ Rext r s n"
    proof
      assume "m1 < m2"
      hence "(p, q) ∈ Rext r s n" using Rext_restrict[OF g _ less_imp_le[OF m2(1)]] m1(2) m2(2) by simp
      thus ?thesis by simp
    next
      assume "m2 < m1"
      hence "(q, p) ∈ Rext r s n" using Rext_restrict[OF g _ less_imp_le[OF m1(1)]] m1(2) m2(2) by simp
      thus ?thesis by simp
    qed
  qed
  thus ?thesis using predecessors_node[OF g] by simp
qed

lemma Rext_strict_part_order: "strict_part_order (Tnodes r s n) (Rext r s n)"
proof -
  have "irrefl_on (Tnodes r s n) (Rext r s n)"
  proof (unfold irrefl_on_def, intro ballI)
    fix p :: "nat × (nat set ⇒ nat)"
    obtain m f where "p = (m, f)" by (cases p) auto
    thus "(p, p) ∉ Rext r s n" by (simp add: Rext_iff)
  qed
  moreover have "trans_on (Tnodes r s n) (Rext r s n)"
  proof (unfold trans_on_def, intro ballI impI)
    fix p q t
    assume pq: "(p, q) ∈ Rext r s n" and qt: "(q, t) ∈ Rext r s n"
    obtain m1 f1 where p: "p = (m1, f1)" by (cases p) auto
    obtain m2 f2 where q: "q = (m2, f2)" by (cases q) auto
    obtain m3 f3 where t: "t = (m3, f3)" by (cases t) auto
    have h: "(m1, f1) ∈ Tnodes r s n" "(m3, f3) ∈ Tnodes r s n" "m1 < m2" "m2 < m3"
      "∀x ∈ [{0..<m1}]⇗r⇖. f2 x = f1 x" "∀x ∈ [{0..<m2}]⇗r⇖. f3 x = f2 x"
      using pq qt p q t by (simp_all add: Rext_iff)
    have "[{0..<m1}]⇗r⇖ ⊆ [{0..<m2}]⇗r⇖" using h(3) by (intro nsets_interval_mono) simp
    hence "∀x ∈ [{0..<m1}]⇗r⇖. f3 x = f1 x" using h(5,6) by auto
    thus "(p, t) ∈ Rext r s n" using h p t by (simp add: Rext_iff)
  qed
  ultimately show ?thesis by (simp add: strict_part_order_def)
qed

text ‹There are only finitely many functions from a given finite set to a given
  finite set, so the nodes up to any given level form a finite set; in
  particular the tree is finitely branching and its set of nodes is countable.›

lemma finite_Tnodes_bounded: "finite {p ∈ Tnodes r s n. fst p < M}"
proof (rule finite_subset)
  show "{p ∈ Tnodes r s n. fst p < M} ⊆ (SIGMA m:{..<M}. [{0..<m}]⇗r⇖ →⇩E {1..s})"
    by (auto simp: Tnodes_def)
  show "finite (SIGMA m:{..<M}. [{0..<m}]⇗r⇖ →⇩E {1..s})"
    by (intro finite_SigmaI finite_PiE finite_imp_finite_nsets) auto
qed

lemma countable_Tnodes: "countable (Tnodes r s n)"
proof (rule countable_subset)
  show "Tnodes r s n ⊆ (SIGMA m:(UNIV::nat set). [{0..<m}]⇗r⇖ →⇩E {1..s})"
    by (auto simp: Tnodes_def)
  show "countable (SIGMA m:(UNIV::nat set). [{0..<m}]⇗r⇖ →⇩E {1..s})"
  proof (rule countable_SIGMA)
    show "countable (UNIV :: nat set)" by simp
  next
    fix m :: nat
    show "countable ([{0..<m}]⇗r⇖ →⇩E {1..s})"
      by (intro countable_finite finite_PiE finite_imp_finite_nsets) auto
  qed
qed

lemma imm_successors_node:
  assumes f: "(m, f) ∈ Tnodes r s n"
  shows "imm_successors (Tnodes r s n) (m, f) (Rext r s n) ⊆
           {Suc m} × ([{0..<Suc m}]⇗r⇖ →⇩E {1..s})"
proof
  fix p
  assume "p ∈ imm_successors (Tnodes r s n) (m, f) (Rext r s n)"
  hence p: "p ∈ Tnodes r s n"
    "height (Tnodes r s n) p (Rext r s n) = height (Tnodes r s n) (m, f) (Rext r s n) + 1"
    by (simp_all add: imm_successors_def)
  obtain m' g where pg: "p = (m', g)" by (cases p) auto
  have g: "(m', g) ∈ Tnodes r s n" using p(1) pg by simp
  have "m' = Suc m" using p(2) pg height_node[OF g] height_node[OF f] by simp
  moreover have "g ∈ [{0..<m'}]⇗r⇖ →⇩E {1..s}" using g by (simp add: Tnodes_def)
  ultimately show "p ∈ {Suc m} × ([{0..<Suc m}]⇗r⇖ →⇩E {1..s})" using pg by simp
qed

lemma finitely_branching_Tnodes: "finitely_branching (Tnodes r s n) (Rext r s n)"
proof (unfold finitely_branching_def, intro ballI)
  fix p
  assume p: "p ∈ Tnodes r s n"
  obtain m f where pmf: "p = (m, f)" by (cases p) auto
  have "imm_successors (Tnodes r s n) p (Rext r s n) ⊆
          {Suc m} × ([{0..<Suc m}]⇗r⇖ →⇩E {1..s})"
    using imm_successors_node[of m f] p pmf by simp
  moreover have "finite ({Suc m} × ([{0..<Suc m}]⇗r⇖ →⇩E {1..s}))"
    by (intro finite_cartesian_product finite_PiE finite_imp_finite_nsets) auto
  ultimately show "finite (imm_successors (Tnodes r s n) p (Rext r s n))"
    by (rule finite_subset)
qed


subsection ‹The tree when Theorem 26.1 fails›

text ‹Assume that Theorem 26.1 fails for ‹r, s, n›: for every ‹m ≥ n› there
  exists a partition ‹f : [{0,…,m-1}]⇗r⇖ → {1,…,s}› having no size-‹n›
  homogeneous set.  Then every level of the tree is nonempty, and what we have
  defined is an infinite tree.›

context
  fixes r s n :: nat
  assumes r: "0 < r"
    and fails: "∀m ≥ n. ∃f ∈ [{0..<m}]⇗r⇖ → {1..s}.
                  ¬ (∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r f Y)"
begin

lemma level_nonempty: "∃f. (m, f) ∈ Tnodes r s n"
proof -
  have "max m n ≥ n" by simp
  then obtain f where f: "f ∈ [{0..<max m n}]⇗r⇖ → {1..s}"
    and noh: "¬ (∃Y ∈ [{0..<max m n}]⇗n⇖. homogeneous r f Y)"
    using fails by blast
  have "(m, restrict f ([{0..<m}]⇗r⇖)) ∈ Tnodes r s n"
    using node_restrict[OF f noh] by simp
  thus ?thesis by blast
qed

lemma root_in_Tnodes: "(0, λx. undefined) ∈ Tnodes r s n"
proof -
  obtain f where f: "(0, f) ∈ Tnodes r s n" using level_nonempty by blast
  hence "f ∈ [{0..<0}]⇗r⇖ →⇩E {1..s}" by (simp add: Tnodes_def)
  hence "f = (λx. undefined)" using nsets_interval_zero[OF r] by simp
  thus ?thesis using f by simp
qed

lemma root_minimum: "minimum (Tnodes r s n) (0, λx. undefined) (Rext r s n)"
proof -
  have "∀p ∈ Tnodes r s n. p ≠ (0, λx. undefined) ⟶ ((0, λx. undefined), p) ∈ Rext r s n"
  proof (intro ballI impI)
    fix p
    assume p: "p ∈ Tnodes r s n" and ne: "p ≠ (0, λx. undefined)"
    obtain m g where pmg: "p = (m, g)" by (cases p) auto
    have g: "(m, g) ∈ Tnodes r s n" using p pmg by simp
    have "m ≠ 0"
    proof
      assume "m = 0"
      hence "g ∈ [{0..<0}]⇗r⇖ →⇩E {1..s}" using g by (simp add: Tnodes_def)
      hence "g = (λx. undefined)" using nsets_interval_zero[OF r] by simp
      thus False using ne pmg ‹m = 0› by simp
    qed
    hence "0 < m" by simp
    hence "((0, restrict g ([{0..<0}]⇗r⇖)), (m, g)) ∈ Rext r s n"
      by (rule Rext_restrict_node[OF g])
    moreover have "restrict g ([{0..<0}]⇗r⇖) = (λx. undefined)"
      using nsets_interval_zero[OF r] by (simp add: restrict_def)
    ultimately show "((0, λx. undefined), p) ∈ Rext r s n" using pmg by simp
  qed
  thus ?thesis using root_in_Tnodes by (simp add: minimum_def)
qed

lemma tree_Tnodes: "tree (Tnodes r s n) (Rext r s n)"
proof (unfold tree_def, intro conjI)
  show "Rext r s n ⊆ Tnodes r s n × Tnodes r s n"
    by (auto simp: Rext_def)
next
  obtain f where f: "(1, f) ∈ Tnodes r s n" using level_nonempty by blast
  hence "((0, λx. undefined), (1, f)) ∈ Rext r s n"
    using root_minimum by (simp add: minimum_def)
  thus "Rext r s n ≠ {}" by blast
next
  show "strict_part_order (Tnodes r s n) (Rext r s n)" by (rule Rext_strict_part_order)
next
  show "∃a. minimum (Tnodes r s n) a (Rext r s n)" using root_minimum by blast
next
  show "∀a ∈ Tnodes r s n. finite (predecessors (Tnodes r s n) a (Rext r s n)) ∧
          total_on (predecessors (Tnodes r s n) a (Rext r s n)) (Rext r s n)"
  proof
    fix a
    assume a: "a ∈ Tnodes r s n"
    obtain M g where aMg: "a = (M, g)" by (cases a) auto
    have g: "(M, g) ∈ Tnodes r s n" using a aMg by simp
    show "finite (predecessors (Tnodes r s n) a (Rext r s n)) ∧
          total_on (predecessors (Tnodes r s n) a (Rext r s n)) (Rext r s n)"
      using predecessors_node[OF g] total_predecessors_node[OF g] aMg by simp
  qed
qed

lemma infinite_Tnodes: "infinite (Tnodes r s n)"
proof
  assume "finite (Tnodes r s n)"
  hence "finite (fst ` Tnodes r s n)" by simp
  moreover have "fst ` Tnodes r s n = ω"
  proof (rule set_eqI)
    fix m :: nat
    obtain f where "(m, f) ∈ Tnodes r s n" using level_nonempty by blast
    hence "m ∈ fst ` Tnodes r s n" by force
    thus "m ∈ fst ` Tnodes r s n ⟷ m ∈ ω" by simp
  qed
  ultimately show False by simp
qed

subsection ‹Theorem 26.1 (Ramsey's theorem)›

text ‹For all ‹r, s > 0› and every ‹n› there is an ‹m ≥ n› such that every
  partition of ‹[{0,…,m-1}]⇗r⇖› into ‹s› classes has a size-‹n› homogeneous
  set.  No condition relating ‹n› and ‹r› is needed: when ‹n < r› a size-‹n›
  set has no size-‹r› subsets, so it is trivially homogeneous.›

theorem Ramsey_Theorem:
  fixes r s n :: nat
  assumes r: "0 < r" and s: "0 < s"
  shows "∃m ≥ n. ∀f ∈ [{0..<m}]⇗r⇖ → {1..s}. ∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r f Y"
proof (rule ccontr)
  txt ‹Suppose that Theorem 26.1 fails.  Then for every ‹m ≥ n› there exists
    a partition ‹f : [{0,…,m-1}]⇗r⇖ → {1,…,s}› having no size-‹n›
    homogeneous set ‹Y›.›
  assume "¬ ?thesis"
  hence fails: "∀m ≥ n. ∃f ∈ [{0..<m}]⇗r⇖ → {1..s}.
                  ¬ (∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r f Y)"
    by blast
  txt ‹Let ‹T› be the set of all such partitions without size-‹n› homogeneous
    sets, ordered by extension.  What we have defined is a tree, with finitely
    many nodes in each level, and infinite.›
  let ?T = "Tnodes r s n" and ?R = "Rext r s n"
  have "tree ?T ?R" using tree_Tnodes[OF r fails] .
  moreover have "countable ?T" by (rule countable_Tnodes)
  moreover have "infinite ?T" using infinite_Tnodes[OF r fails] .
  moreover have "finitely_branching ?T ?R" by (rule finitely_branching_Tnodes)
  txt ‹König's lemma then tells us there will be an infinite branch, that is,
    an infinite set ‹B› of partitions, each one extending the ones below it,
    none of them having a size-‹n› homogeneous set.  This is the step of the
    proof that depends on the compactness theorem.›
  ultimately obtain B where B: "infinite_path B ?T ?R"
    using Koenig_Lemma_countable by blast
  hence BT: "B ⊆ ?T" and Btot: "total_on B ?R" and Binf: "infinite B"
    by (auto simp: infinite_path_def path_def sub_linear_order_def)
  txt ‹Since every level of the tree is finite, the branch contains partitions
    of arbitrarily large levels.›
  have high: "∃m g. (m, g) ∈ B ∧ M ≤ m" for M
  proof (rule ccontr)
    assume low: "¬ (∃m g. (m, g) ∈ B ∧ M ≤ m)"
    have "B ⊆ {p ∈ ?T. fst p < M}"
    proof
      fix p
      assume p: "p ∈ B"
      obtain m g where pmg: "p = (m, g)" by (cases p) auto
      have "m < M" using low p pmg by auto
      thus "p ∈ {p ∈ ?T. fst p < M}" using p pmg BT by auto
    qed
    hence "finite B" using finite_Tnodes_bounded finite_subset by blast
    thus False using Binf by contradiction
  qed
  txt ‹Any two partitions of the branch assign the same value to any argument
    in both domains, since one of them extends the other.›
  have agree: "g1 x = g2 x"
    if "(m1, g1) ∈ B" "(m2, g2) ∈ B" "x ∈ [{0..<m1}]⇗r⇖" "x ∈ [{0..<m2}]⇗r⇖"
    for m1 g1 m2 g2 x
  proof (cases "(m1, g1) = (m2, g2)")
    case True
    thus ?thesis by simp
  next
    case False
    hence "((m1, g1), (m2, g2)) ∈ ?R ∨ ((m2, g2), (m1, g1)) ∈ ?R"
      using Btot that(1,2) unfolding total_on_def by blast
    thus ?thesis using that(3,4) by (auto simp: Rext_iff)
  qed
  txt ‹We can then define a partition ‹F : [ω]⇗r⇖ → {1,…,s}› as follows: for
    any size-‹r› subset ‹x› of ‹ω›, ‹F(x)› is the common value ‹g(x)› of the
    partitions ‹g› of the branch whose domain contains ‹x›.›
  define F where "F = (λx. snd (SOME p. p ∈ B ∧ x ∈ [{0..<fst p}]⇗r⇖) x)"
  have F_eq: "F x = g x" if "(m, g) ∈ B" "x ∈ [{0..<m}]⇗r⇖" for m g x
  proof -
    let ?p = "SOME p. p ∈ B ∧ x ∈ [{0..<fst p}]⇗r⇖"
    have "∃p. p ∈ B ∧ x ∈ [{0..<fst p}]⇗r⇖" using that by force
    hence p: "?p ∈ B ∧ x ∈ [{0..<fst ?p}]⇗r⇖" by (rule someI_ex)
    have "snd ?p x = g x" using agree[of "fst ?p" "snd ?p" m g x] p that by simp
    thus ?thesis by (simp add: F_def)
  qed
  have F: "F ∈ [ω]⇗r⇖ → {1..s}"
  proof (rule Pi_I)
    fix x
    assume x: "x ∈ [ω]⇗r⇖"
    hence "finite x" by (simp add: nsets_def)
    then obtain M where xM: "x ⊆ {..<M}" using finite_nat_bounded by blast
    obtain m g where mg: "(m, g) ∈ B" "M ≤ m" using high by blast
    have xm: "x ∈ [{0..<m}]⇗r⇖" using x xM mg(2) by (auto simp: nsets_def)
    have "g ∈ [{0..<m}]⇗r⇖ →⇩E {1..s}" using mg(1) BT by (auto simp: Tnodes_def)
    hence "g x ∈ {1..s}" using xm by (rule PiE_mem)
    thus "F x ∈ {1..s}" using F_eq[OF mg(1) xm] by simp
  qed
  txt ‹By the infinitary version of Ramsey's theorem, ‹F› has an infinite
    homogeneous set: there is an infinite ‹Y› and a ‹j› with ‹1 ≤ j ≤ s›
    such that ‹F : [Y]⇗r⇖ → {j}›.›
  obtain Y j where Y: "infinite Y" and FY: "F ∈ [Y]⇗r⇖ → {j}"
    using Infinitary_Ramsey_Theorem[OF r s F] by blast
  txt ‹Let ‹Z› be a set of ‹n› elements of ‹Y› (the book takes the first ‹n›
    elements of ‹Y›; any ‹n› of them will do), and take a partition ‹g› of the
    branch at a level ‹m› large enough that ‹Z ⊆ {0,…,m-1}›.›
  obtain Z where Z: "Z ⊆ Y" "finite Z" "card Z = n"
    using infinite_arbitrarily_large[OF Y] by blast
  obtain M where ZM: "Z ⊆ {..<M}" using finite_nat_bounded[OF Z(2)] by blast
  obtain m g where mg: "(m, g) ∈ B" "M ≤ m" using high by blast
  have Zm: "Z ∈ [{0..<m}]⇗n⇖" using Z ZM mg(2) by (auto simp: nsets_def)
  txt ‹Then ‹Z› is a size-‹n› subset of ‹{0,…,m-1}› with ‹g(x) = F(x) = j› for
    all size-‹r› subsets ‹x› of ‹Z›.  In other words, ‹Z› is a size-‹n›
    homogeneous set for ‹g›,›
  have "g ∈ [Z]⇗r⇖ → {j}"
  proof (rule Pi_I)
    fix x
    assume x: "x ∈ [Z]⇗r⇖"
    have "x ∈ [Y]⇗r⇖" using x Z(1) nsets_mono by blast
    hence "F x ∈ {j}" using FY by (rule funcset_mem[rotated])
    moreover have "x ∈ [{0..<m}]⇗r⇖" using x Zm by (auto simp: nsets_def)
    hence "F x = g x" using F_eq[OF mg(1)] by blast
    ultimately show "g x ∈ {j}" by simp
  qed
  hence "∃Y ∈ [{0..<m}]⇗n⇖. homogeneous r g Y" using Zm by blast
  txt ‹which is impossible, since ‹g› is in ‹T›.  This contradiction completes
    the proof.›
  moreover have "(m, g) ∈ ?T" using mg(1) BT by blast
  ultimately show False by (simp add: Tnodes_def)
qed
